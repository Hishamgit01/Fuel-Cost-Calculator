# ⛽ FuelCalc — Modern Trip & Fuel Utility Web App

A sleek, Apple-inspired **Fuel & Trip Utility Web App** designed to help users calculate trip costs, split expenses among passengers, calculate vehicle mileage, compare EV vs. Internal Combustion Engine (ICE) travel costs, and share trip summaries effortlessly.

---

## ✨ Features

* **🚘 Trip Cost Calculator:** Calculate total fuel consumption and trip expenses for both **One-Way** and **Round Trips**.
* **👥 Passenger Expense Splitter:** Automatically calculates the **Cost Per Person** based on the number of passengers.
* **⚡ EV vs. Fuel Mode:** Switch seamlessly between Petrol/Diesel and Electric Vehicles (EV) to compare travel costs and energy efficiency.
* **⛽ Flexible Mileage Calculator:** Compute vehicle efficiency by either:
* **Fuel Consumed (Liters)**
* **Total Amount Spent (₹)** (calculated dynamically using the current fuel price)


* **📱 WhatsApp & Summary Sharing:** One-click copy/share formatted trip breakdowns directly to WhatsApp.
* **📜 Local History Tracking:** Automatically saves recent calculations locally in your browser so you can view past trips without losing data.
* **🎨 Apple-Inspired Glassmorphic UI:** Premium UI featuring responsive layouts, smooth micro-interactions, and built-in **Light / Dark Mode** toggles.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
* **UI Style:** Glassmorphism, Apple Human Interface Design principles
* **Storage:** Browser `localStorage` API
